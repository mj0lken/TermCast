TermCast - a TinyCast fork

A native SwiftUI & AppKit launcher that brings an integrated, multi-tab PTY terminal directly into the command palette—alongside fuzzy search, clipboard history, snippets, and Raycast extensions.

Download DMG View on GitHub

Core capabilities

Inline Command Detection

Type a shell command in the root launcher to switch into monospace, reveal the active folder strip underneath, cycle recent folders with ⇧⇥, and run with ⇧↵.

Multi-Tab Live PTYs

Enter with >. Manage tabs (⌘N, ⌘1–⌘9), stream full ANSI color, send stdin, interrupt (⌘.), and persist cd state across runs.

Powered by TinyCast

Inherits TinyCast’s fast native launcher: apps, clipboard history, snippets, calculator, window management, and Raycast extensions in JavaScriptCore.

Quick Install

Download the signed .dmg from GitHub Releases, drag Termcast.app to /Applications, and enable Settings → Terminal. Or build locally: 

git clone https://github.com/mj0lken/TermCast.git && cd TermCast && ./Scripts/build-dmg.sh

Terminal Shortcuts

  • Jump to Terminal>
  • Run command in tab⇧↵
  • Cycle recent folder⇧⇥
  • New / switch tab⌘N ⌘1–9
  • Stop / close tab⌘. ⌃X
