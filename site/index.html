TermCast — a Tinycast fork

A native macOS menu-bar launcher built on Tinycast with three flagship upgrades: a live multi-tab PTY terminal, Hyper Key trackpad sliders for per-display brightness & volume, and drag-to-snap + traffic-light window management.

Three built-in power tools, zero background bloat

Replaces a standalone drop-down terminal, a trackpad brightness/DDC utility, and a tiling window manager inside a single <100 MB accessory app.

01 · Terminal Mode

Multi-Tab Live PTY Terminal

Type any shell command in the root launcher to switch into monospace, cycle recent working folders with ⇧⇥, and stream real zsh PTY output with interactive stdin, ANSI themes, and VM-slab scrollback.

02 · Hyper Key + Trackpad

Per-Display Brightness & Volume Sliders

Remap Caps Lock to Hyper (⌃⌥⌘⇧), then hold Hyper and two-finger scroll vertically on your trackpad. Brightness targets only the display under your cursor—Apple displays via DisplayServices and external monitors via DDC/CI.

03 · Window Management

Drag-to-Snap, Green Button & Grids

Drag windows to screen edges or corners with live Liquid Glass previews and drag-away size restore, hover any window's green zoom button for a tiling popover, or draw custom tiles on a 6×4, 12×8, or 24×12 grid.
