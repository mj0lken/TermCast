TermCast — a Tinycast fork

A native macOS menu-bar launcher built on Tinycast with four flagship upgrades: a live multi-tab PTY terminal, a Notch HUD and tray, Hyper Key trackpad sliders for per-display brightness & volume, and drag-to-snap + traffic-light window management.

01 · Terminal

Live shell tabs, right in the launcher

Type a command and it runs in a real zsh PTY. Hybrid mode keeps search open while your sessions stay live in ⌘1–9 tabs.

03 · Hyper Key + Trackpad

One key for every chord, and sliders on your trackpad

Caps Lock becomes ⌃⌥⇧⌘. Hold it and two-finger scroll to set display brightness, keyboard backlight or volume, depending on where your fingers land.

Move & Resize
04 · Window Management

Snap windows the way you already move them

Drag to an edge or corner, hover the green button for a tiling menu, or bind any of 45 halves, quarters, thirds and sizing commands to a shortcut.

Also in the box

The whole Tinycast launcher, too

Everything the launcher already did ships alongside the four upgrades above, and Clipboard and Notebook have both been rebuilt for this release.

  • Raycast extensions

    Store extensions run natively in JavaScriptCore, right inside the launcher.

  • AI chat and Quick AI

    Use local CLI providers such as Claude, Codex, Antigravity and OpenCode, and connect MCP tool servers.

  • Clipboard history New

    A category sidebar sorts text, links, colours, images, code, PDFs and other files, with a preview drawer and search that ranks titles first.

  • Notebook New

    Plain Markdown notes as a launcher screen: search filters every note and the editor renders Markdown in place. You can also open it from the notch.

  • Snippets and inline maths

    Keyword snippet expansion, plus units, live currency rates and time zones answered as you type.

  • Portable settings

    Single-file .termcast backups, imports from Tinycast and Raycast, and an optional settings.json mirror.
