TermCast - a TinyCast fork

A fork that brings the full power of a native terminal directly into TinyCast—run shell commands, cycle working folders, and manage live multi-tab PTY sessions without ever leaving the launcher palette.

Download DMG View on GitHub
$ 
brew install --cask mj0lken/tap/termcast

Core capabilities

Inline Shell Execution

Type any CLI command in the root launcher to switch into monospace, preview your active folder bar, and execute straight into a tab.

⇧↵ Run ⇧⇥ Cycle folder

Multi-Tab Live PTYs

Real zsh pseudo-terminals with full ANSI color streaming, interactive stdin, and persistent cd state across runs.

> Open ⌘1–9 Tabs ⌘. Stop

Everything in TinyCast

Fuzzy app & file search, clipboard history, snippets, inline calculator, window snapping, and native Raycast extensions in JavaScriptCore.

Zero deps Raycast JS
